# Board game preference candidates

Status: non-canonical research note

Purpose: keep a compact list of games that appear compatible with the current preference hypothesis. This file is not a source of game rules, editions, availability, venue information, or verified personal ratings.

## Preference hypothesis

Prioritize games with:
- low randomness or meaningful control over randomness
- strong player interaction through shared systems
- open or mostly open information
- tactical adaptation to opponents
- blocking, timing, auctions, shared markets, or contested spaces
- medium to heavy strategic depth

De-emphasize games dominated by:
- negotiation as the primary mechanism
- performance / acting
- memory tests
- player elimination
- outcomes driven mainly by luck
